# Context

## What it does

Portable skill pack for Claude Code and Cursor: UI-first frontend design, rebuild-from-reference, and backend engineering, with provenance and taste-memory.

## Who it is for

Builders using Cursor / Claude Code who want consistent design + engineering agent workflows.

## How it works

Canonical skills live under `skills/` and are symlinked into `.cursor/skills`, `.claude/skills`, and `.agents/skills`. Companions (shadcn, 21st, Taste Skill, Impeccable) are installed or linked alongside.

## Forge

GitHub only — see `AGENTS.md`.

## Out of scope (for now)

- Hosting a product app inside this repo
- Cursor Origin as a git/PR host
